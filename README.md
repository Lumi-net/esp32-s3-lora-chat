# esp32-s3-lora-chat

**ELC (ESP32-S3 LoRa Chat)** — 基于 ESP32-S3 的 LoRa 点对点聊天设备，支持 T9 键盘输入、LVGL GUI、外部 Flash 存储、WiFi 时间同步和低功耗休眠。

[用户使用手册(凑合看吧 个别地方可能不太对)](USER_MANUAL.md)

PCB见`pcb/`目录，3D模型见`3d/`目录。做的比较粗糙，都是排针连接，因为我不想买一大堆小东西自己焊。
